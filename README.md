# 🍎 Астра Сторе — Telegram Bot

Бот для магазина Apple-техники: каталог, ремонт, Trade-In, связь с менеджером.

## 📁 Структура проекта

```
astra_bot/
├── bot.py                    # Точка входа
├── config.py                 # Настройки (токен, ID менеджера)
├── requirements.txt
├── keyboards/
│   └── main_menu.py          # Клавиатуры
└── handlers/
    ├── catalog.py            # Каталог товаров
    ├── repair.py             # Запись на ремонт
    ├── tradein.py            # Trade-In оценка
    └── manager_contact.py    # Связь с менеджером
```

## 🚀 Быстрый старт

### 1. Установите зависимости
```bash
pip install -r requirements.txt
```

### 2. Настройте config.py

Откройте `config.py` и заполните:

```python
BOT_TOKEN = "ВАШ_ТОКЕН"       # Токен от @BotFather
MANAGER_CHAT_ID = 123456789    # Ваш Telegram ID
```

**Как получить токен:** напишите @BotFather → /newbot → следуйте инструкциям

**Как узнать свой Chat ID:** напишите боту @userinfobot → он пришлёт ваш ID

### 3. Запустите бота
```bash
python bot.py
```

## ✏️ Редактирование каталога

Откройте `handlers/catalog.py` и найдите переменную `CATALOG`.
Добавляйте/удаляйте товары по образцу:

```python
{
    "name": "iPhone 16 Pro 256GB",
    "price": "109 990 ₽",
    "desc": "Новый, запечатанный. Гарантия Apple 1 год.",
    "emoji": "📱"
}
```

## 💡 Возможности бота

| Функция | Описание |
|---|---|
| 📱 Каталог новых | Показывает новые устройства Apple |
| ♻️ Каталог б/у | Показывает устройства б/у |
| 🔧 Ремонт | Форма записи: устройство → проблема → контакт |
| 🔄 Trade-In | Форма оценки: устройство → модель → состояние → контакт |
| 💬 Менеджер | Свободное сообщение → уведомление менеджеру |

Все заявки приходят менеджеру в Telegram с полными данными клиента.
